# Russian Trader V2

Backend V2 + frontend control room for a multi-tenant HFT trading platform (MOEX + Crypto).

## Status
- Multi-tenant core: in progress
- HFT execution pipeline: active
- Tinkoff integration: in progress
- Crypto exchanges: Bybit/OKX/KuCoin basic integration

## Quick Start
```bash
cd backend
npm install
npm run dev
```

Frontend preview:
```bash
cd frontend
npm install
npm run dev
```

See `backend/.env.example` for required variables.
