# Trader

Личное веб-приложение для AI-анализа акций и БПИФ Московской биржи, рассчитанное в том числе на начинающих инвесторов.

- **Рынок** — индекс Мосбиржи, ключевая ставка ЦБ, курс доллара, 44 компании индекса с весами и стоимостью лота, AI-обзор всего рынка.
- **Вотчлист** — свои бумаги с котировками, последним AI-сигналом и сравнительным AI-обзором.
- **Страница бумаги** — свечной график, технические индикаторы, AI-анализ: сигнал (покупать / держать / продавать) с уверенностью, «простыми словами», аргументы за и против, риски, уровни на графике. Можно задать свой вопрос («у меня 50 000 ₽, стоит ли брать?»).
- **Прогнозы аналитиков и сделки инсайдеров** (T-Invest API) — консенсус брокерских домов с целевыми ценами, раскрытые сделки менеджмента; оба идут и в интерфейс, и в промпт.
- **Спор «бык против медведя»** внутри каждого анализа и **табло точности AI**: прошлые вердикты сверяются с реальной ценой через 7 и 30 дней, исходы передаются модели при следующем анализе той же бумаги.
- **Отчётность и дивиденды** (через T-Invest API) — выручка, прибыль, долг, P/E, P/B, ROE, дивдоходность, история и объявленные дивиденды с последним днём покупки.
- **Количественная оценка и скринер** — детерминированный счёт 0–100 (тренд, сила относительно индекса, фундаментал) по всем бумагам индекса, плюс честная walk-forward проверка на истории: есть ли у счёта предсказательная сила. Результат проверки передаётся AI, чтобы он не переоценивал тренд.
- **Отрасли и аналоги** — сектор каждой бумаги (T-Invest), отраслевой срез портфеля против индекса, таблица аналогов по сектору (P/E, дивиденды, ROE, оценка); AI видит концентрацию по отраслям и сравнение с соседями.
- **Новости из первоисточников** — Интерфакс, Коммерсантъ, Ведомости, Финам, Прайм, пресс-релизы ЦБ и Мосбиржи; привязка к тикерам, тип события по правилам, тон и важность — моделью, раз на заголовок; блок «важные события за 36 часов».
- **ОФЗ как ориентир** — доходности гособлигаций на 1/3/5 лет рядом с дивидендами и ставкой ЦБ; AI сравнивает акцию с безрисковой альтернативой.
- **Для новичка** — календарь дивидендов по вотчлисту и портфелю, AI-разбор портфеля целиком (концентрация, доля денег, что сократить/добавить), плашка свежести котировки, еженедельный дайджест в Telegram.
- **Торговля в песочнице** — учебный счёт Т-Инвестиций с виртуальными рублями: покупка и продажа (рыночные и лимитные заявки) с подтверждением, портфель, история операций. Без плеча и шортов; реальная торговля намеренно не подключена.
- **Арена** — турниры автономных AI-агентов на виртуальных счетах внутри приложения (сделки по живой цене биржи с комиссией 0,05%, настоящих денег нет). Три турнира: «Основной» (пять характеров: фундаменталист, трендовик, контрарианец, рантье, квант), «Модели» (один нейтральный характер на каждой модели) и «Стили» (каждый характер на каждой модели). По будням в 10:00, 13:00 и 16:00 МСК все агенты получают одинаковый пакет данных (рынок, новости, скоринг бумаг индекса), объясняют ход мыслей и предлагают сделки в JSON; риск-слой в коде проверяет каждую (не больше 10% счёта в бумаге, 3 заявки в день, 12 сделок в неделю, стоп при просадке 15%, без плеча и шортов). Турнирная таблица: доходность, просадка, Шарп, сделки, комиссии против индекса Мосбиржи и ОФЗ; журнал решений с моделью, пауза и стоп. Модели — облачная из `.env` и любые локальные из Ollama (`ollama pull qwen3:14b`); локальный ход занимает 3–5 минут. Раунды идут только пока запущен бэкенд.
- **Новости** — свежие заголовки по компании и рынку (Google Новости).
- **Учёт российской специфики** — AI видит ставку ЦБ, курс рубля, сравнение бумаги с индексом и знает про дивидендные гэпы, санкционные и регуляторные риски.
- **Обучение** — короткий справочник для новичка: что покупать на бирже, брокеры и лоты, налоги и ИИС, дивиденды, правила безопасности, словарь индикаторов.

Данные берутся из бесплатного [MOEX ISS](https://iss.moex.com) (задержка до 15 минут) и с сайта ЦБ РФ (ставка, курс). AI — любой OpenAI-совместимый API, по умолчанию DeepSeek.

> AI анализирует только цены, обороты и макро-контекст (новостей и отчётности не видит). Это инструмент для анализа, а не индивидуальная инвестиционная рекомендация — решение принимает пользователь.

## Стек

| | |
|---|---|
| Backend | Node.js 22+, Express 5, PostgreSQL, zod |
| Frontend | React 19, Vite, Tailwind CSS 4, TanStack Query, lightweight-charts |
| Деплой | Docker (один контейнер: API + статика), Amvera |

## Локальный запуск

```bash
npm install
npm run db:up                         # Postgres в Docker на порту 5440
cp backend/.env.example backend/.env  # заполнить APP_PASSWORD, JWT_SECRET, AI_API_KEY
npm run dev                           # API :3001 + фронтенд :5173
```

Открыть http://localhost:5173 и войти с паролем `APP_PASSWORD`. Миграции БД применяются автоматически при старте.

Прочие команды: `npm test` (тесты индикаторов), `npm run typecheck`, `npm run build`, `npm start`.

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `APP_PASSWORD` | да | Пароль входа, ≥ 8 символов |
| `JWT_SECRET` | да | Секрет сессий, ≥ 32 символов (`openssl rand -hex 32`) |
| `DATABASE_URL` | да в проде | Строка подключения к Postgres |
| `DATABASE_SSL` | | `true` для облачной БД с TLS |
| `AI_API_KEY` | для AI | Ключ API. Без него работает всё, кроме анализа |
| `AI_BASE_URL` | | По умолчанию `https://api.deepseek.com` |
| `AI_MODEL` | | По умолчанию `deepseek-chat` |
| `WEBAUTHN_RP_ID` / `WEBAUTHN_ORIGINS` | | Домен и origin сайта для passkey (по умолчанию localhost) |
| `OLLAMA_URL` | | Локальная Ollama для агентов арены, по умолчанию `http://localhost:11434` |
| `TINKOFF_TOKEN` | для отчётности | Токен T-Invest API (для песочницы) |
| `TINKOFF_SANDBOX` | | `true` — песочница (по умолчанию) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | для дайджеста | Бот от @BotFather и id чата; дайджест по понедельникам в 9:00 МСК |

Другой провайдер — поменять `AI_BASE_URL` и `AI_MODEL`, например OpenRouter (`https://openrouter.ai/api/v1`) даёт доступ к Claude, GPT и др.

## Деплой на Legion

Домашний сервер за Caddy с клиентским сертификатом, 2FA и passkey — см. [docs/LEGION.md](docs/LEGION.md); обновление одной командой `scripts/deploy-legion.sh`.

## Деплой на Amvera

1. В проекте Amvera → «Переменные» добавить **секреты**: `DATABASE_URL`, `APP_PASSWORD`, `JWT_SECRET`, `AI_API_KEY`.
2. Запушить репозиторий — Amvera соберёт `Dockerfile` по `amvera.yaml`.

## Структура

```
backend/
  src/
    index.ts          запуск + миграции
    app.ts            Express, роуты, раздача фронтенда
    auth.ts           вход по паролю, cookie-сессия
    moex.ts           клиент MOEX ISS с кэшем
    context.ts        контекст рынка: индекс, ставка ЦБ, курс
    news.ts           новости (Google News RSS, запасной источник)
    feeds.ts          первоисточники RSS, привязка к тикерам, тон событий
    tinkoff.ts        T-Invest API: дивиденды, отчётность, прогнозы, инсайдеры
    scorecard.ts      точность прошлых вердиктов
    scoring.ts        количественная оценка 0–100
    ofz.ts            доходности ОФЗ (MOEX)
    digest.ts         Telegram-дайджест по расписанию
    trading.ts        торговля в песочнице: счёт, портфель, заявки
    arena.ts          арена: турниры, агенты-персоны, виртуальные счета, пакет данных, риск-слой, расписание, таблица
  certs/              сертификат Минцифры (нужен для API Т-Банка)
    indicators.ts     технические индикаторы
    ai.ts             промпт, вызов LLM, валидация ответа
    routes/           market, watchlist, analysis, review, trading, calendar, screener
  migrations/         SQL-миграции
  test/
frontend/src/
  pages/              Market, Dashboard, Portfolio, Instrument, History, Learn, Login
  components/         график, индикаторы, карточка анализа, поиск
```

Старый прототип (HFT / multi-tenant) сохранён в ветке `legacy`.
